# •Tree Data Structure 
## A tree is a graph which does not contain any cycle in it. Tree also have a set of nodes and edges similar to graph. This data structure provides many with best and efficient time and space complexity. The structure of tree has one root node and the nodes joined by the edges from the root node are its child nodes , the root node work as a parent for these nodes , similar to this structure every node has its own child except the leaf node , they are the last nodes in the tree, they does not contain any child so their child nodes are represented by NULL. The tree works as a fundamental data structure for some other special data structures like Binary trees , B trees , Heaps , Red-Black trees and many others.
